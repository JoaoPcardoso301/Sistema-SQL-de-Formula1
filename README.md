# Sistema-SQL-de-Formula1
Projeto simples de um sistema de Fórmula 1 desenvolvido em SQL.

# Sobre o projeto
Este projeto foi criado com o objetivo de praticar conceitos de banco de dados e modelagem relacional utilizando SQL.
O sistema simula informações de um campeonato de Fórmula 1, contendo dados sobre:

  -Países
  -Equipes
  -Pilotos
  -Corridas
  -Participantes.
Além da criação das tabelas, o projeto também possui:

  -Relacionamentos entre tabelas
  -Chaves primárias e estrangeiras
  -Inserts para popular o banco
  -Consultas SQL
  -Alterações em tabelas
  -Operações com filtros, médias e ordenações.


# Tecnologias utilizadas

  -SQL
  -MySQL
  -phpMyAdmin
  -XAMPP

# Como executar

Criar um banco de dados MySQL.
Copiar o conteúdo do arquivo contendo os comandos SQL e executar os comandos no phpMyAdmin ou MySQL Workbench.
